# TriggeredSendTypeEnum

The TriggeredSendTypeEnum object defines the type of triggered send to be used.

## Properties

| Name | Data Type | Description |
| --- | --- | --- |
| Batched | Enumeration | Sends the triggered send in batches. |
| Continuous | Enumeration | Sends the triggered sends as received. Deprecated. |
| Scheduled | Enumeration | Sends the triggered send at a specific time. |
