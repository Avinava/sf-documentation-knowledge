# SubscriberAddressStatus

The SubscriberAddressStatus object defines the valid status values for a subscriber's address.

## Properties

| Name | Data Type | Description |
| --- | --- | --- |
| InActive | Enumeration | Indicates a subscriber address has an inactive status. |
| OptedIn | Enumeration | Indicates a subscriber status has opted in to receive messages. |
| OptedOut | Enumeration | Indicates a subscriber status has opted out of receiving messages. |
