# Retrieve the Tracking Information for a Triggered Send

This scenario contains information about retrieving tracking information associated with a triggered send. You can use this information to determine how many instances of a triggered send have occurred and what actions have taken place as a result of those triggered sends (such as opens, bounces, and clicks).
