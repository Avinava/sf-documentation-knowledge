# DateTimeUnitOfMeasure

The DateTimeUnitOfMeasure object indicates the unit of measure for time values in data retention settings for data extensions.

## Properties

| Name | Data Type | Description |
| --- | --- | --- |
| Days | Enumeration | Indicates that the time value used for data retention of data extensions is measured in days. |
| Months | Enumeration | Indicates that the time value used for data retention of data extensions is measured in months. |
| Weeks | Enumeration | Indicates that the time value used for data retention of data extensions is measured in weeks. |
| Years | Enumeration | Indicates that the time value used for data retention of data extensions is measured in years. |
