# 373000-373999 FilterDefinition Object Error Codes

| Error | Message |
| --- | --- |
| 373000 | Filter definition create calls cannot specify the ObjectID property |
| 373001 | Either object ID or customer key is required for the DataSource if the DataSource is a data extension |
| 373002 | The data extension specified as DataSource was not found |
| 373003 | Filter definition name is required for Create calls |
| 373004 | Filter definition name already exists. Please specify a unique name |
| 373005 | Filter definition customer key already exists. Please specify a unique customer key |
| 373006 | Either object ID or customer key is required to perform an update |
| 373007 | Filter definition was not found using either the ID or the name |
| 373008 | DataFilter is required for Create calls |
| 373009 | The DataFilter that was provided is invalid |
| 373010 | The type for [object] does not allow the operation specified: [operation] |
| 373011 | The property provided could not be found: [property] |
| 373012 | Invalid filter part. Only filter parts of ComplexFilterPart and SimpleFilterPart are allowed for filter definitions |
