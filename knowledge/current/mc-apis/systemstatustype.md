# SystemStatusType

The SystemStatusType object contains the types of system status.

## Properties

| Name | Data Type | Description |
| --- | --- | --- |
| InMaintenance | Enumeration | Indicates the system is currently in maintenance mode (read-only). |
| OK | Enumeration | Indicates the system is functioning normally (read-only). |
| UnplannedOutage | Enumeration | Indicates the API system encountered an unplanned outage. |
