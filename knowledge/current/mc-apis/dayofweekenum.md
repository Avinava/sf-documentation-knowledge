# DayOfWeekEnum

| --- | --- | --- |

| Monday | Enumeration | Indicates whether the recurrence happens on Monday. A value of true indicates that the recurrence occurs on a Monday. |
| Saturday | Enumeration | Indicates whether a recurrence takes place on a Saturday. A value of true indicates that the recurrence happens on a Saturday. |

| Thursday | Enumeration | Indicates a recurrence occurs on a Thursday. |
| Tuesday | Enumeration | Indicates a recurrence pattern on a Tuesday. A value of true indicates that the event recurs on a Tuesday. |
