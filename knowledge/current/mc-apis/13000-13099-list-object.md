# 13000-13099 List Object

| Error | Message | Resolution |
| --- | --- | --- |
| 13000 | List Not Found | Ensure your call includes the correct ListID for the list you wish to access. |
| 13001 | List ID Not Specified | Ensure your call includes the correct ListID for the list you wish to access |
| 13002 | Exception During Delete | Review the error information provided by the exception and resolve the issue before attempting another deletion. |
| 13003 | Salesforce Not Enabled | Ensure that your account includes a properly configured Salesforce integration. |
| 13004 | Unknown List ID | Ensure your call includes the correct ListID for the list you wish to access. |
| 13005 | List Subscriber Error | Ensure that you correctly included all relevant subscriber information. |
| 13006 | On List Already | You cannot add a subscriber to the same list twice. |
| 13007 | Not On List | Ensure that you correctly included all relevant subscriber information. |
| 13008 | Salesforce List Not Allowed | Ensure the list you selected does not use the Salesforce integration. |
| 13009 | List Category Invalid | Ensure that you provide valid category information for this list. |
| 13010 | List Name Too Long | Ensure that your list name does not exceed 50 characters. |
| 13011 | Multiple master lists returned | Ensure that you reference the correct master list for your account. Ids are (ID \| OID \| Key). |
| 13012 | List Cannot Be Updated | You cannot make updates to the selected list. Ensure that you reference the correct list in your call. |
| 13013 | List Validation Error | Ensure that the selected list meets the validation standards for sends. |
| 13014 | Invalid List Status | Ensure that your call includes a valid status for the specified list |
