# SalutationSourceEnum

The SalutationSourceEnum object specifies storage area for header and footer used in an email message.

## Properties

| Name | Data Type | Description |
| --- | --- | --- |
| ContentLibrary | Enumeration | Specifies that an email message header or footer comes from the content library. |
| Default | Enumeration | Specifies default source of header and footer salutation values when building an email (SalutationSourceEnum). Use the default action when saving an object. (SaveAction) |
| None | Enumeration | Default response type for AsyncResponseType. Indicates no specified header or footer values. |
