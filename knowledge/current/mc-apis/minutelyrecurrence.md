# MinutelyRecurrence

The MinutelyRecurrence object specifies an minutely recurrence pattern and value. This recurrence can be used with campaigns.

## Properties

| Name | Data Type | Description |
| --- | --- | --- |
| MinuteInterval | xsd:int | Indicates a recurrence interval of minutes. |
| MinutelyRecurrencePatternType | MinutelyRecurrencePatternTypeEnum | Specifies the pattern type with which minutely recurrences happen. Valid values include Interval. |
