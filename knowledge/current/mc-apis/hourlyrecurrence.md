# HourlyRecurrence

The HourlyRecurrence object specifies an hourly recurrence pattern and value. This recurrence can be used with campaigns.

## Properties

| Name | Data Type | Description |
| --- | --- | --- |
| HourInterval | xsd:int | Specifies hour interval in hourly recurrence pattern. |
| HourlyRecurrencePatternType | HourlyRecurrencePatternTypeEnum | Defines the pattern type for an hourly recurrence. Valid values include:Interval |
