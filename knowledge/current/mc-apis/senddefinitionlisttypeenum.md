# SendDefinitionListTypeEnum

The SendDefinitionListTypeEnum object defines how Marketing Cloud acts upon a send definition list.

## Properties

| Name | Data Type | Description |
| --- | --- | --- |
| DomainExclusion | Enumeration | Indicates domains to be excluded from sends. |
| ExclusionList | Enumeration | Indicates the subscriber list used to exclude an audience from a particular send. |
| OptOutList | Enumeration | Defines audience that has opted out of receiving more sends; refers to a publication list in Marketing Cloud. |
| SourceList | Enumeration | Indicates list used to send to audience. The source list corresponds to a subscriber list within an account. |
