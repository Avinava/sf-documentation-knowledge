# 402000-402999 Reply Mail Management Configuration Error Codes

| Error | Message | Resolution |
| --- | --- | --- |
| 402000 | Reply Mail Management is not activated in your account until the MX Record Redirect Complete is marked as True | Update your MX Record and Set DNSRedirectComplete to True. |
| 402001 | To activate Reply Mail Management Email Reply Name must be complete |  |
| 402002 | To activate Reply Mail Management Reply Subdomain must be complete |  |
| 402003 | Email reply address subdomain value has to be same with reply subdomain value |  |
| 402004 | To activate Reply Mail Management Email From Address must be complete |  |
| 402005 | Please enter valid Email Reply Address |  |
| 402006 | To activate Reply Mail Management Forwarding Email Address must be complete |  |
| 402007 | Please enter valid Forwarding Email Address |  |
| 402008 | Reply Mail Management Business rule not enabled |  |
| 402009 | You need to set true for at least one of the Unsubscribe terms |  |
