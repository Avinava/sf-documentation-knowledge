# Multiply

## **Overview**

Returns the product of multiplying two numbers.

### **Syntax**

Multiply(1, 2)
| Ordinal | Type |  | Description |
| --- | --- | --- | --- |
| 1 | numeric | Required | First number |
| 2 | numeric | Required | Second number |

### Usage

Given @abc=10 and @def=5

```
%%=Multiply(@abc,@def)=%%
```

System returns:

```
50
```
