# Trim

## **Overview**

Returns the value of the string parameter with the leading and trailing white space removed.

### **Syntax**

Trim(1)
| Ordinal | Type |  | Description |
| --- | --- | --- | --- |
| 1 | string | Required | String value |

### Usage

```
%%=Trim('   Text   ')=%%
```

System returns:

```
Text
```
