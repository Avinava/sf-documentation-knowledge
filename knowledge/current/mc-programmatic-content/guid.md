# GUID

# GUID

## **Overview**

Returns a new GUID as a string value.

### **Syntax**

GUID()

### Usage

```
var @myGUID
set @myGUID = GUID()
```

The system created the @myGUID variable and sets the value of that variable with the string generated by GUID().
