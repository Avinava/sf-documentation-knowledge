# Lowercase

## **Overview**

Returns the specified value in all lowercase letters.

### **Syntax**

Lowercase(1)
| Ordinal | Type |  | Description |
| --- | --- | --- | --- |
| 1 | string | Required | Specified string value |

### Usage

Given @name=MARY KAY

```
%%=Lowercase(@name)=%%
```

System returns:

```
mary kay
```
