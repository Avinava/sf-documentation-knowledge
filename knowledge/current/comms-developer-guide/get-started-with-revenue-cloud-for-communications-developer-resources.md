# Get Started with Revenue Cloud for Communications Developer Resources

Get a single, unified system to automate your CRM processes. Use the developer sources of Revenue Cloud for Communications to automate the backend work to support the end-to-end communications service providers implement effective and consistent customer management processes.

| Available in: Lightning Experience |
| --- |
| Available in: Enterprise, Unlimited, and Developer Editions |


Learn more about the developer resources that are available for these components.

## Multisite

Create and manage location-based quotes and orders, and enjoy flexible location data management with your location component.

-   Use [standard objects](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/b2b_std_objects_parent.htm "This section provides a list of standard objects and their standard fields.") and fields to manage location-based quotes and orders.
-   Use [business APIs](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/comms_api_rest_references.htm "You can access Revenue Cloud for Communications APIs using REST endpoints. These REST APIs follow similar conventions as Connect REST APIs.") to update recipient group and split a quote line item.

## Consumer Sales

Create and manage a seamless digital journey for business-to-consumer (B2C) where anonymous shoppers can easily find, configure, and purchase products.

-   Use [standard objects](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/consumer_sales_std_objects_parent.htm "The Consumer Sales data model provides objects and fields to manage cart item attribute and relationships between the cart items.") and fields to manage products, rules, and catalogs.
-   Use [business APIs](https://developer.salesforce.com/docs/atlas.en-us.260.0.comms_developer_guide.meta/comms_developer_guide/comms_api_rest_references.htm) to serve catalog definitions, and retrieve and update a product’s configuration from a configurator, or to access configurator capabilities by integrating with any front-end application to users or applications. You can also place a sales transaction.
-   Use [invocable actions](https://developer.salesforce.com/docs/atlas.en-us.260.0.comms_developer_guide.meta/comms_developer_guide/resources_actions_invocable.htm) to create an order from a cart, and create or update an asset from an order through invocable actions.
