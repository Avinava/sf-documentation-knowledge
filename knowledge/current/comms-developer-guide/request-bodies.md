# Request Bodies

Here’s a list of Revenue Cloud for Communications request bodies.

-   **[Recipient Group Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_recipient_group_input.htm)**
    Input representation of the recipients required to add or remove them from a recipient group.
-   **[Split Recipient Group Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_recipient_split_group_input.htm)**
    Input representation of the quote line item to split them from a recipient group.
-   **[Additional Fields Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_additional_fields_input.htm)**
    Input representation of the additional standard or custom fields to include in the response.
-   **[Bulk Product Details Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_bulk_product_details_input.htm)**
    Input representation of the request to retrieve details of multiple products.
-   **[Configuration Options Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_configuration_options_input.htm)**
    Input representation for the configuration options.
-   **[Configurator Added Node Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_configurator_added_node_input.htm)**
    Input representation of the nodes to be added to a product configuration.
-   **[Configurator Deleted Node Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_configurator_deleted_node_input.htm)**
    Input representation of the nodes to be deleted from a product configuration.
-   **[Configurator Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_configurator_input.htm)**
    Input representation of the request to modify the product configuration.
-   **[Configurator Options Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_configurator_options_input.htm)**
    Input representation of the request to get the product configuration options that’s passed to the configurator.
-   **[Configurator Preference Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_configurator_preference_input.htm)**
    Input representation of the configuration preference for the place sales transaction request.
-   **[Configurator Updated Node Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_configurator_updated_node_input.htm)**
    Input representation of the nodes to be updated in a product configuration.
-   **[User Context Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_configurator_user_context_input.htm)**
    Input representation of the request to get the context details of a user, which are used for qualification rules.
-   **[Context Data Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_context_data_input.htm)**
    Input representation of the context data.
-   **[Context Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_context_info_input.htm)**
    Input representation of the context that's associated with a sales transaction for a quote or an order.
-   **[Filter Criteria Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_filter_criteria_input.htm)**
    Input representation of the criteria to filter records based on supported properties.
-   **[Filter Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_filter_input.htm)**
    Input representation of the request to filter records.
-   **[Object Graph Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_object_graph_input.htm)**
    Input representation of an sObject with a graph ID.
-   **[Object Input Map](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_object_input_representation_map.htm)**
    Input representation of an sObject record in a key-value map format.
-   **[Object with Reference Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_object_with_reference_input.htm)**
    Input representation of a list of records to be inserted or updated. To update a record, specify the record ID.
-   **[Sales Transaction Bulk Operation Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_place_sales_transaction_bulk_operation_input.htm)**
    Input representation of the details of a request to perform bulk operations for specified quote line items or order products.
-   **[Sales Transaction Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_place_sales_transaction_input.htm)**
    Input representation of the details of the request to place a sales transaction, such as a quote or an order.
-   **[Product Data Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_product_data_input.htm)**
    Input representation of the product details such as the product ID and product selling model ID.
-   **[Product Details Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_product_details_input.htm)**
    Input representation of the request to get product details.
-   **[Product List Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_product_list_input.htm)**
    Input representation of the request to retrieve a list of products.
-   **[Related Object Filter Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_related_object_filter_input.htm)**
    Input representation of the request to filter records of a related object.
-   **[User Context Input](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_requests_user_context_input.htm)**
    Input representation of the details with the user context.
