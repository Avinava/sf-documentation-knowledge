# Response Bodies

Here’s a list of Revenue Cloud for Communications API response bodies.

-   **[Updating Recipient Group Error Output](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_update_recipient_group_error_output.htm)**
    Output representation detailing the reasons why the recipient group was not updated.
-   **[Updating Recipient Group Output](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_update_recipient_group_output.htm)**
    Output representation of synchronous operation that’s executed to add or remove recipients to a recipient group.
-   **[Splitting Group Error Output](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_splitting_group_error_output.htm)**
    Output representation detailing the reasons why the recipient group was not updated.
-   **[Splitting Group Output](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_splitting_group_output.htm)**
    Output representation of synchronous operation that’s executed to add or remove recipients to a recipient group.
-   **[API Status](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_api_status_output.htm)**
    Output representation of the API status.
-   **[Configurator Message](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_configurator_message_output.htm)**
    Output representation of the messages of a product configurator.
-   **[Configuration Details](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_configurator_output.htm)**
    Output representation of the product configuration details.
-   **[Configurator Product Catalog](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_configurator_product_catalog_output.htm)**
    Output representation of the product catalog.
-   **[Configurator Product Recommendations](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_configurator_product_recommendation_output.htm)**
    Output representation of the details of the product recommendations.
-   **[Configurator Qualification Context](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_configurator_qualification_context_output.htm)**
    Output representation of the qualification context in a product configuration.
-   **[Configurator UI Treatment](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_configurator_u_i_treatment_output.htm)**
    Output representation of the details of the UI treatments of a product configurator. The details include the product configuration rule actions to override the disable or hide behavior in the UI for product options, product attributes, and attribute picklist values.
-   **[Bulk Product Details](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_cpq_base_bulk_details_output.htm)**
    Output representation of the response that contains the details of multiple products.
-   **[CPQ Base List](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_cpq_base_list_output.htm)**
    Output representation of the list of catalogs, categories, or products based on the request.
-   **[CPQ Message](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_cpq_message_output.htm)**
    Output representation of the API messages.
-   **[Facet Value](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_facet_value.htm)**
    Output representation of the facet values found in the search result.
-   **[Sales Transaction Error Response](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_place_sales_transaction_error_response.htm)**
    Output representation of the error details associated with the API request.
-   **[Sales Transaction](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_place_sales_transaction_output.htm)**
    Output representation of the request to create a sales transaction.
-   **[Sales Transaction Context](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_sales_transaction_context_output.htm)**
    Output representation of the context details that are associated with a sales transaction.
-   **[Search Products Facet](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_search_products_facet.htm)**
    Output representation of the details of the faceted search.
-   **[User Context](atlas.en-us.comms_developer_guide.meta/comms_developer_guide/connect_responses_user_context_output.htm)**
    Output representation of the user context details.
