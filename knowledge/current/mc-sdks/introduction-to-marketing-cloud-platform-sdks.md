# Introduction to Marketing Cloud Platform SDKs

> This documentation applies to the Marketing Cloud platform SDKs. For MobilePush SDKs, review [MobilePush SDKs](atlas.en-us.noversion.mc-sdks.meta/mc-sdks/mobile-push-sdk.htm). For the Content Builder SDK, review [Extend Content Builder](https://developer.salesforce.com/docs/atlas.en-us.noversion.mc-app-development.meta/mc-app-development/content-sdk.htm).

The Marketing Cloud platform SDKs provide a cross-functional framework around the SOAP and REST APIs. This framework allows developers to integrate APIs using native language code libraries. The platform SDKs use both the SOAP and REST APIs to provide agnostic protocol interfaces and automated token management.

We currently offer six platform SDKs.

-   [C# SDK](atlas.en-us.noversion.mc-sdks.meta/mc-sdks/getting-started-with-the-csharp-sdk.htm)
-   [Java SDK](atlas.en-us.noversion.mc-sdks.meta/mc-sdks/getting-started-with-the-java-sdk.htm)
-   [Node SDK](https://github.com/salesforce-marketingcloud/FuelSDK-Node)
-   [PHP SDK](atlas.en-us.noversion.mc-sdks.meta/mc-sdks/getting-started-with-the-php-sdk.htm)
-   [Ruby SDK](atlas.en-us.noversion.mc-sdks.meta/mc-sdks/getting-started-with-the-ruby-sdk.htm)
-   [Python SDK](atlas.en-us.noversion.mc-sdks.meta/mc-sdks/getting-started-with-the-python-sdk.htm)

We also provide SDKs for iOS and Android to use with MobilePush.

## Support

The Salesforce Marketing Cloud Platform SDKs, excluding the MobilePush SDK and Content Builder SDK, are community-supported projects. The SDK source code, samples, and documentation are publicly available on Github to use as-is or fork and modify for your needs. We invite everyone in the community to collaborate with us on Github and submit pull requests to help improve the source code and samples.

-   File issues and feature requests on Github.
