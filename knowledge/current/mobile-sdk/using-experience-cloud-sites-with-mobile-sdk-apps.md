# Using Experience Cloud Sites With Mobile SDK Apps

Experience Cloud sites can include up to millions of users, as allowed by [Salesforce limits](https://help.salesforce.com/apex/HTViewHelpDoc?id=limits_communities_parent.htm&language=en_US). With proper configuration, your customers can use their Experience Cloud site login credentials to access your Mobile SDK app. You can also brand your Experience Cloud site and login screen.

To learn more about Experience Cloud sites, see [Set Up and Manage Experience Cloud Sites](https://help.salesforce.com/apex/HTViewHelpDoc?id=networks_overview.htm&language=en_US) in Salesforce Help.

-   **[Experience Cloud Sites and Mobile SDK Apps](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/communities_mobilesdk.htm)**
    To enable Experience Cloud site members to log into your Mobile SDK app, set the appropriate permissions in Salesforce, and change your app’s login server configuration to recognize your site URL.
-   **[Set Up an API-Enabled Profile](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/communities_profile.htm)**

-   **[Set Up a Permission Set](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/communities_permission_set.htm)**

-   **[Grant API Access to Users](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/communities_users_api_access.htm)**

-   **[Configure the Login Endpoint](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/communities_login_endpoint.htm)**

-   **[Brand Your Experience Cloud Site](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/communities_customize_branding_mobilesdk.htm)**
    If you are using the Salesforce Tabs + Visualforce template, you can customize the look and feel of your Experience Cloud site in Experience Workspaces. You can customize by adding your company logo, colors, and copyright. Customizing these elements ensures that your Experience Cloud site matches your company’s branding and is instantly recognizable to your site members.
-   **[Customize Login, Self-Registration, and Password Management for Your Experience Cloud Site](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/communities_customize_login_mobilesdk.htm)**
    Configure the standard login, logout, password management, and self-registration options for your Experience Cloud site, or customize the behavior with Apex and Visualforce.
-   **[Use Your Branded Login Page](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/communities_branded_login.htm)**
    Starting with Mobile SDK 5.2, you can display a branded Experience Cloud site login page on your client app.
-   **[Using External Authentication With Experience Cloud Sites](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/communities_external_auth_using.htm)**
    You can use an external authentication provider, such as Facebook©, to log Experience Cloud site users into your Mobile SDK app.
-   **[Example: Configure an Experience Cloud Site For Mobile SDK App Access](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/communities_tutorial.htm)**
    Configuring your Experience Cloud site to support logins from Mobile SDK apps can be tricky. This tutorial helps you see the details and correct sequence first-hand.
-   **[Example: Configure an Experience Cloud Site For Facebook Authentication](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/communities_external_auth_example.htm)**
    You can extend the reach of your Experience Cloud site by configuring an external authentication provider to handle site logins.
