# Migrating from the Previous Release

If you’re upgrading an app built with Salesforce Mobile SDK 11.0, follow these instructions to update your app to 11.1.

If you’re upgrading an app that’s built with a version earlier than Salesforce Mobile SDK 11.0, start upgrading with [Migrating from Earlier Releases](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/migration_migrating_from_earlier.htm).
