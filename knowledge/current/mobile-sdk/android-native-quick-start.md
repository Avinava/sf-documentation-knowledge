# Android Native Quick Start

Use the following procedure to get started quickly.

1.  Make sure you meet all of the [native Android requirements](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/android_requirements.htm).
2.  Install [Mobile SDK for Android](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/install_android.htm "Before you try to create Mobile SDK apps for Android—native, hybrid, or React Native—install the Android native development environment."). If you prefer, you can install Mobile SDK from the [GitHub Repositories GitHub Repositories](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/install_github.htm "More adventurous developers can delve into the SDK, keep up with the latest changes, and possibly contribute to SDK development through GitHub. Using GitHub allows you to monitor source code in public pre-release development branches. In this scenario, your app includes the SDK source code, which is built along with your app.") instead.
3.  At the command line, run the forcedroid application to create a new [Android project](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/android_new_project.htm), and then run that app in Android Studio or from the command line.
4.  Follow the instructions at [Setting Up Sample Projects in](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/android_project_setup.htm).
