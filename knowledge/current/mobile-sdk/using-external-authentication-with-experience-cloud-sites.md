# Using External Authentication With Experience Cloud Sites

You can use an external authentication provider, such as Facebook©, to log Experience Cloud site users into your Mobile SDK app.

For more information, see [Authenticate Experience Cloud Site Users](https://help.salesforce.com/s/articleView?id=experience.networks_authentication_options.htm&language=en_US).
