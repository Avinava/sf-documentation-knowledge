# About PIN Security

Beginning in version 9.2, Mobile SDK uses the mobile device PIN instead of an app-specific PIN and simplifies the passcode flow.

-   For iOS, see [About Login and Passcodes](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/ios_native_login_passcodes.htm).
-   For Android, see [Using Passcodes](atlas.en-us.noversion.mobile_sdk.meta/mobile_sdk/android_passcodes.htm).
