# Request Bodies

Learn more about the available Product Catalog Management API request bodies.

-   **[Additional Fields Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_product_catalog_additional_fields_input.htm)**
    Input representation of the additional standard or custom fields to be included in the response.
-   **[Bulk Product Details Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_products_detail_bulk_input.htm)**
    Input representation of the request to retrieve the details of multiple products.
-   **[Catalog Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_catalog_input.htm)**
    Input representation of the request to retrieve catalog records.
-   **[Criteria Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_criteria.htm)**
    Input representation of the filter criteria item request.
-   **[Data Rounding Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_data_rounding_input.htm)**
    Input representation of the details of the data rounding input.
-   **[Data Row Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_data_row_input.htm)**
    Input representation of the details of the input for a data rounding request.
-   **[Deep Clone Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_deep_clone_input.htm)**
    Input representation of the details of the object and associated record to be cloned.
-   **[Field Data Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_field_data_input.htm)**
    Input representation of the details of the field data input.
-   **[Filter Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_filter.htm)**
    Input representation of the filter request.
-   **[Include Object Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_include_object_input.htm)**
    Input representation of the object to include in the response.
-   **[Index Configuration Collection Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_index_configuration_collection_input.htm)**
    Input representation of the collection of index configurations.
-   **[Index Configuration Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_index_configuration_input.htm)**
    Input representation of the request to persist the index configuration.
-   **[Index Setting Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_index_setting_input.htm)**
    Input representation of the index setting.
-   **[Options Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_options.htm)**
    Reserved for internal use.
-   **[Order Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_order.htm)**
    Input representation of the sort order item request.
-   **[Product Classification Details Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_product_classification_details_input.htm)**
    Input representation of the request to fetch details of product classification records, including their attributes and attribute categories.
-   **[Product Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_product_input.htm)**
    Input representation of a product in the catalog.
-   **[Related Object Filters Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_related_object_filters_input.htm)**
    Input representation of the request to filter related objects.
-   **[Related Object Node Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_related_object_node_input.htm)**
    Input representation of the details of a related object node.
-   **[Related Records Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_related_records_input.htm)**
    Input representation of the request to retrieve related ProductRampSegment or ProductUsageGrant records for Product2 object.
-   **[Run-time Catalog Snapshot Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_runtime_catalog_snapshot_input.htm)**
    Input representation of the details of a run-time catalog snapshot for deployment.
-   **[Setting Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_setting_input.htm)**
    Input representation of the details of the index setting.
-   **[Snapshot Deployment Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_snapshot_deployment_input.htm)**
    Input representation of the request to deploy a run-time catalog snapshot.
-   **[Sort Input](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_requests_sort.htm)**
    Input representation of the sort request.
