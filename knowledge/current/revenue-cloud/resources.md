# Resources

Learn more about the available Salesforce Pricing resources.

-   **[PBE Derived Pricing (POST)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_pbe_source_pricing_derived_product.htm)**
    Get the source product for the Price Book Entry (PBE) derived pricing.
-   **[Price Context (POST)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_price_context.htm)**
    Perform a pricing request by using the instance ID of a context.
-   **[Pricing (POST)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_headless.htm)**
    Create and hydrate context instance in a single request. Provide a comprehensive response that contains final pricing details per line items and related errors, if any.
-   **[API Execution Logs (GET)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_execution_logs.htm)**
    Get the log details of a pricing API execution record by using the execution ID.
-   **[Pricing Process Execution (GET)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_pricing_process_execution.htm)**
    Get the execution details of a pricing process by using the execution ID.
-   **[Pricing Process Execution for Line Items (GET)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_process_execution_line_item_details.htm)**
    Get the pricing execution details for the line items of a pricing process by using the execution ID and execution type.
-   **[Pricing Data Sync (GET)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_pricing_data_sync.htm)**
    Sync pricing data to ensure that the lookup tables contain the latest pricing data.
-   **[Pricing Recipe (GET)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_pricing_recipe.htm)**
    Get the mapping details of pricing recipes to the associated pricing recipe table.
-   **[Pricing Recipe Mapping (POST)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_price_recipe_mapping.htm)**
    Create a mapping between the pricing recipe and the Decision Tables. Post recipes with lookup tables or procedures.
-   **[Pricing Versioned Revision Details (POST)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_versioned_revise_details.htm)**
    Create revisions of a pricing request with versions for adjustment entities.
-   **[Pricing Waterfall (GET)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_pricing_waterfall_fetch.htm)**
    Get the persisted price waterfall that stores the process logs. Price waterfall provides insights into every step of the pricing process.
-   **[Pricing Waterfall (POST)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_pricing_waterfall_post.htm)**
    Create a log of price waterfall. Price waterfall provides insights into every step of the pricing process.
-   **[Procedure Plan Definitions (GET, POST)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_get_procedure_plan_definition_records.htm)**
    Get the records of procedure plan definitions. Additionally, create a record of a procedure plan definition.
-   **[Procedure Plan Definition By ID (GET, PATCH, DELETE)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_get_procedure_plan_definition_by_ID.htm)**
    Get, update, or delete a procedure plan definition record by using the record ID.
-   **[Procedure Plan Evaluation By Object (POST)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_evaluate_procedure_plan_definition_by_object.htm)**
    Evaluate a procedure plan definition based on a primary object to check for prerequisites such as usage type and context mapping details.
-   **[Procedure Plan Evaluation By Definition Name (POST)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_evaluate_procedure_plan_by_definition_name.htm)**
    Evaluate a procedure plan definition based on the name of a definition to check for prerequisites such as usage type and context mapping details.
-   **[Procedure Plan Version (POST)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_create_procedure_plan_version_record.htm)**
    Create records of a procedure plan version with details.
-   **[Procedure Plan Version Details (GET, PATCH, DELETE)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_get_procedure_plan_version_details.htm)**
    Get, update, or delete a procedure plan definition version record by using the record ID.
-   **[Pricing Simulation Input Variables With Data (GET)](atlas.en-us.revenue_lifecycle_management_dev_guide.meta/revenue_lifecycle_management_dev_guide/connect_resources_get_pricing_simulation_data_with_variables.htm)**
    Get details of the pricing simulation input variables along with associated data.
