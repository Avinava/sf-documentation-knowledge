# Object Details Output

Represents the details of the transformation object.

| Property Name | Type | Description | Filter Group and Version | Available Version |
| --- | --- | --- | --- | --- |
| errorReason | String | Indicates the reason for transformation failure. | Small, 55.0 | 55.0 |
| inputIds | String[] | The record IDs of the input object corresponding to the output object. | Small, 55.0 | 55.0 |
| isSuccess | Boolean | Indicates if the transformation is successful (true) or not (false). | Small, 55.0 | 55.0 |
| outputId | String | The output record ID. | Small, 55.0 | 55.0 |
